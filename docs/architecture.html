// terraform-aws-sns-sqs

Production-ready AWS SNS topics and SQS queues with subscriptions, dead-letter queues, FIFO, message filtering, KMS encryption, and CloudWatch alarms.

Terraform ≥ 1.3.0 AWS ≥ 5.0 MIT License

Executive Summary

This module manages AWS messaging infrastructure including SNS topics (standard and FIFO), SQS queues with comprehensive configuration, dead-letter queues with configurable retention, SNS-to-SQS subscriptions with message filtering, KMS encryption for both topics and queues, access policies for cross-service publish permissions, and CloudWatch alarms for queue depth, DLQ depth, and message age. It supports FIFO ordering, deduplication, long polling, redrive policies, and multiple subscription protocols (SQS, Lambda, HTTP/S, email, SMS, Firehose).

Security Controls

KMS Encryption

Both SNS topics and SQS queues support KMS encryption with configurable key reuse period

SQS Managed SSE

SQS-managed server-side encryption enabled by default when KMS is not configured

IAM Queue Policies

Least-privilege policies granting SNS topics permission to send to specific SQS queues

Input Validation

Validated visibility_timeout (0-43200s), message_retention (60-1209600s), max_message_size (1KB-256KB)

Production Readiness Checklist

  • Enable KMS encryption on all topics and queues handling sensitive data
  • Configure DLQs for all SQS queues with appropriate max_receive_count
  • Enable CloudWatch alarms with cloudwatch_alarms.enabled = true
  • Set alarm_actions to an SNS topic for PagerDuty/Slack notifications
  • Use FIFO queues for ordering-sensitive workloads
  • Configure message filtering to reduce consumer processing load
  • Set visibility_timeout to 6x the average processing time
  • Enable long polling (receive_wait_time_seconds = 20) to reduce empty responses
  • Use content-based deduplication for idempotent FIFO operations
  • Monitor DLQ depth alarms -- any messages indicate processing failures

Deployment

module "messaging" {
  source = "path/to/terraform-aws-sns-sqs"

  sns_topics = {
    "order-notifications" = {
      display_name = "Order Notifications"
    }
  }

  sqs_queues = {
    "order-processor" = {
      visibility_timeout_seconds = 60
    }
  }

  sns_subscriptions = {
    "orders-to-processor" = {
      topic_arn = module.messaging.sns_topic_arns["order-notifications"]
      protocol  = "sqs"
      endpoint  = module.messaging.sqs_queue_arns["order-processor"]
    }
  }
}
